## 大陆优化VPS到底在优化什么？

优化的是回程路由，部分商家会做到双向优化。你访问海外服务器时，请求数据从国内出发走“去程”，服务器返回数据走“回程”，两条路的路径经常不一样，体验好坏主要看回程。

国内三大运营商各有两套网：电信有163老骨干和CN2（AS4809），其中CN2 GIA是全程独立通道，CN2 GT则混跑163；联通有AS4837普通网和AS9929精品网；移动的国际出口叫CMI。晚高峰（大约晚上8点到11点）的拥堵发生在163、4837这类普通通道上——大家挤同一条国际出口，延迟、丢包、掉速都发生在这里。CN2 GIA和双向9929是运营商单独划出来的通道，所以贵，但高峰期表现稳定得多。

对大陆用户来说，线路优先级大致是：**CN2 GIA ≥ 双向9929 > AS4837 > 普通163/国际BGP**，价格同样从高到低。机房位置是另一个变量：香港离得近，延迟普遍只有几十毫秒；日本次之；美西最远，但回程线路好的话，实用速度并不吃亏。所以选大陆优化VPS本质上是两道题：先定线路等级，再按预算定机房。

## 下单前值得留意的几个坑

买大陆优化VPS，踩坑的高发区集中在这几处，下单前逐条对一遍：

- **带宽数字不等于国内速度**。100Mbps标的是国际段带宽，走普通线路晚高峰照样只有1-2MB/s。看回程线路等级，比看带宽大小有用。
- **“不限流量”要看带宽**。带宽只给5Mbps的不限流量，一个月实际跑不了多少数据，而且这类机器通常是超售大户。
- **IP质量**。超售商家的IP段可能早被Netflix、TikTok、ChatGPT等平台拉黑，买回来什么都解锁不了。有解锁需求的，确认能测试或能退款再付年付。
- **NAT共享IP**。几块钱一个月的机器多是NAT机，分到的是共享IP上的几个端口，需要独立公网IP的直接排除。
- **流量计费方向**。有的商家按双向计费，进加出相加，实际可用量比标称少一半。下单前确认计费方式。
- **运营年限**。极低价加新上线的商家存在跑路风险，运营了几年的商家和今年刚开张的商家，可信度不一样。
